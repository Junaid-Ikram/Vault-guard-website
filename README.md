## What is the Privacy Policy URL for Google Play Console?

Once you host this folder online (see 1-minute hosting options below), your public Privacy Policy URL will be:

```text
https://<your-domain-or-subdomain>/privacy.html
```

Paste this exact link into Google Play Console under **App content** &rarr; **Privacy policy**.

## 3 Free Ways to Host This in 60 Seconds

### Option 1: Netlify Drop (Easiest — 30 Seconds, No Code / No Account Needed)
1. Open [app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
2. Drag and drop the `vaultguard-website` folder directly into the browser box.
3. It will immediately give you a free, live HTTPS URL (e.g. `https://vaultguard-security.netlify.app`).
4. Your Privacy Policy URL will be:
   `https://vaultguard-security.netlify.app/privacy.html`

---

### Option 2: GitHub Pages (Free Forever)
1. In your GitHub repository for VaultGuard (or a new repo named `vaultguard-website`), push this folder.
2. Go to repository **Settings** &rarr; **Pages**.
3. Under **Branch**, select `main` (or `gh-pages`) &rarr; `/ (root)` &rarr; click **Save**.
4. Your site will be live at:
   `https://<your-github-username>.github.io/vaultguard-website/privacy.html`

---

### Option 3: Vercel (Free)
1. Go to [vercel.com](https://vercel.com).
2. Click **Add New** &rarr; **Project** &rarr; Import your GitHub repo or drag-and-drop the `vaultguard-website` folder.
3. Click **Deploy**.
4. Your link will be: `https://vaultguard-website.vercel.app/privacy.html`.
